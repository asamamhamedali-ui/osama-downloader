# OSAMA DOWNLOAD X

نسخة تأسيسية قابلة للفتح في Android Studio.

## ما الذي يعمل في هذه النسخة؟
- واجهة Android أصلية باستخدام Kotlin وJetpack Compose.
- تصميم داكن عربي.
- لصق رابط HTTP/HTTPS مباشر وبدء تنزيله عبر Android DownloadManager.
- إظهار تقدم التنزيل وحالته أثناء بقاء التطبيق مفتوحاً.
- استقبال الروابط النصية من قائمة المشاركة في التطبيقات والمتصفحات.
- استقبال روابط HTTP/HTTPS عند اختيار التطبيق لفتحها.
- تصنيف أولي حسب امتداد اسم الملف.

## ما الذي لم يُنفذ بعد؟
- محرك تقسيم مخصص متعدد الاتصالات.
- تحكم فعلي في سرعة التنزيل.
- استئناف مخصص وإدارة أجزاء التنزيل.
- حفظ سجل التطبيق محلياً عبر Room.
- قائمة انتظار متقدمة وأولويات.
- متصفح داخلي والتقاط أحداث التنزيل من WebView.
- إضافة Chrome/Firefox.
- تحليل روابط منصات التواصل.
- طبقة AI.

هذه ليست وظائف مخفية أو أزرار شكلية؛ ستضاف على مراحل بعد اختبار الأساس.

## متطلبات البناء
- Android Studio حديث.
- JDK 17.
- Android SDK Platform 35.
- اتصال إنترنت أول مرة لتنزيل Gradle dependencies.

## طريقة التشغيل
1. فك ضغط الملف.
2. افتح مجلد `OSAMA_DOWNLOAD_X` من Android Studio.
3. انتظر Gradle Sync.
4. شغّل التطبيق على جهاز Android أو المحاكي.
5. جرّب رابط تنزيل مباشر لملف تملكه أو مسموح بتنزيله.

## ملاحظات مهمة
- Android DownloadManager هو محرك المرحلة الأولى؛ لا يوفر API عاماً للتحكم اليدوي في عدد الأجزاء أو حد السرعة.
- بعض الخوادم تمنع الاستئناف أو تتطلب جلسة/مصادقة.
- استقبال المشاركة لا يعني أن التطبيق يستطيع اعتراض كل تنزيل يبدأ داخل أي متصفح تلقائياً.
- لا يدعم هذا الإصدار استخراج فيديوهات محمية أو تجاوز DRM أو قيود المنصات.
- إصدار Android 13 وما بعده قد يتطلب إذن الإشعارات لعرض إشعارات التطبيق؛ تنزيل Android DownloadManager يدير إشعاراته بنفسه وفق النظام.
